
# Telecom Microservices

A Spring Boot-based Telecom Management System built using a microservices architecture.

## Project Overview

This project aims to develop a telecom management platform that provides customer management, mobile plan management, and subscription management capabilities through independently developed microservices.

The system is designed to demonstrate practical implementation of Java, Spring Boot, REST APIs, database integration, and microservices architecture.

## Microservices

| Microservice | Responsibility |
|---|---|
| Customer Service | Manage customer information |
| Plan Service | Manage telecom plans |
| Subscription Service | Manage customer subscriptions |

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- REST APIs
- Maven
- SQL Database
- Git & GitHub
